# Contributing to NeuroState

Thank you for your interest in contributing to the **NeuroState** research artifact and mobile runtime ecosystem!

## Code of Conduct
We are committed to providing a friendly, safe, and welcoming environment for all contributors.

## Reporting Issues & Reproduction Discrepancies
If you encounter discrepancies while replicating benchmark tables or running test harnesses:
1. Check the logs under `benchmarks/reports/`.
2. Open an issue with your device model, Android/iOS version, and hardware telemetry traces.

## Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure all micro-benchmarks pass.
3. Submit a PR describing your proposed optimization or test harness extension.
